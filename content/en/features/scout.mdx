<Card title="What Scout does">

- Searches ten databases in parallel and merges the results.
- Deduplicates the same paper across sources and shows which databases returned
  it.
- Every result is a real record — Scout never invents a reference.
- Verifies any result's DOI against Crossref on demand.
- Save what you want to keep — the saved list exports as a `.bib`.

</Card>

## Why this matters

Literature search usually means running the same query across half a dozen
database websites and hand-merging the results. Scout queries ten live scholarly
databases at once, deduplicates records that share a DOI, and ranks what is
left. Every result is a real record returned by one of those sources; nothing is
generated by a language model, so you never get a plausible-looking reference
that does not exist.

## Examples

**Search a topic.** Query `CRISPR` returns ranked real papers, each with title,
authors, year, venue, citation count and DOI, plus a relevance score and a
"confirmed by N databases" badge when the same DOI came back from several
sources.

## Questions people ask

**Does Scout invent or summarise papers with AI?** No. Every result is a real
record returned by one of the ten databases. Nothing in the list is
model-generated.

**Why does a paper say "confirmed by 3 databases"?** That record came back
independently from three sources, matched by DOI — or by an exact title match
where a source carries no DOI. It signals the metadata is right, not that the
paper is good.

**Are the citation counts exact?** They are whatever the source reported and can
differ slightly between databases. Treat them as indicative, not authoritative.
