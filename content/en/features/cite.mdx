<Card title="What Cite does">

- Detects the sentences in your text that need citation support.
- Gives each claim real candidate sources from live scholarly databases —
  topical matches to review, not a guarantee that a source supports the claim.
- Exports the sources you keep as a `.bib` file.
- Copies citations in APA, MLA, Chicago, Vancouver or IEEE format.

</Card>

## Why this matters

When you already have the prose, the hard part is finding a real, citable source
for each specific claim. Cite reads your text, isolates the statements that need
support, and searches the same live scholarly databases Scout uses to suggest
sources for each one. Every suggestion is a real record from a database, not a
model-generated citation.

Claim-splitting and source-matching are LLM-assisted, so review each suggestion
before you accept it: the model decides which sentences need a source, and the
databases decide what the source is.

## Examples

**Claim to sources.** Paste a paragraph — Cite splits it into individual claims,
finds candidate real sources for each, ranks them by relevance, and lets you
accept the ones that fit and export them as a `.bib`.

## Questions people ask

**Does Cite write citations with AI?** It uses a model only to identify which
sentences need a citation. Every suggested source is a real record returned by a
scholarly database, never invented.

**Will it cite every sentence?** No. It targets statements that actually warrant
a source, and you choose which suggestions to accept.

**Is my pasted text stored?** No text is kept after the check completes.
