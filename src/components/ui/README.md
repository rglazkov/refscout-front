shadcn/ui primitives: generated by the CLI and edited by hand.

`field.tsx` and `blocked-button.tsx` are the exceptions - it is ours. It is a control for an
action that cannot run, and it exists because there are no disabled buttons in
this product: a blocked one stays focusable, says why when it is pressed,
and records the attempt.

`field.tsx` holds the input, the text area and the native drop-down. They carry
the same two surfaces the buttons do - `--control-ground` on the page ground,
`--control-card` on a card - because a field filled with `--background` inside a
dialogue panel is that panel, to the byte, and disappears into it.
